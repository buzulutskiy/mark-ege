# Марк · Подготовка к ЕГЭ

Минималистичное приложение для телефона и компьютера: недельный план, плановая длительность, фактическое время, отметка «Сделано», процент выполнения, динамика времени по неделям и пробники с графиком баллов. Точные темы не вводятся.

## Запуск

Сайт: https://buzulutskiy.github.io/mark-ege/

Локально: установите Node.js, выполните `npm start` в папке проекта и откройте http://127.0.0.1:4173. Установка библиотек и сборка не нужны.

Исходные файлы — `dist`. GitHub Pages публикует копию из `docs` на ветке `main`. После изменения исходников скопируйте файлы из `dist` в `docs` и отправьте изменения в GitHub.

## Общий прогресс через Gist

1. Откройте приложение по персональной ссылке с `#gist=ID`. ID Gist не включён в публичный исходный код. Без токена работает только просмотр.
2. Марк нажимает «Доступ Марка» и вводит отдельный GitHub-токен **владельца Gist** с разрешением Gists: write (fine-grained) или scope gist (classic). Токен другого аккаунта не сможет записывать в этот Gist.
3. Токен хранится только в оперативной памяти страницы, отправляется только в API GitHub, не попадает в URL, localStorage и репозиторий. После перезагрузки его надо ввести снова. Для записи в Gist токен необходим: один пароль приложения GitHub Pages этого не заменяет.
4. Изменения отправляются автоматически; дождитесь надписи «Сохранено в Gist» перед закрытием. При ошибке остаётся локальный черновик, кнопка «Обновить» повторяет отправку. После перезагрузки повторно подключите токен, чтобы восстановить черновик.
5. Родитель использует ту же персональную ссылку без токена. Данные обновляются каждые 2 минуты при открытой странице либо по кнопке «Обновить».
6. Кнопка «Ссылка для просмотра» копирует ссылку без токена.

Секретный Gist скрыт из публичного списка, но **доступен любому обладателю ссылки**. Не публикуйте персональную ссылку в репозитории. GitHub сохраняет историю версий Gist. Используйте отдельный токен с минимальными правами, а не основной токен аккаунта: права Gists могут распространяться на другие Gist владельца.

Рассчитано на одного редактора (Марк). Перед записью проверяется версия: при обнаружении чужих изменений запись останавливается, черновик сохраняется. GitHub Gist не предоставляет транзакционное редактирование: не редактируйте одновременно на нескольких устройствах.

Если Gist ещё не создан: создайте секретный Gist с файлом `mark-progress.json`, содержащим `{"tasks":[],"exams":[],"weeks":[]}`, и подключите его. При первом открытии недели с правом записи появится шаблон.

## План и динамика

Старт занятий — 14 сентября 2026 года. До этой даты шаблоны не создаются; при открытии приложения показывается стартовая неделя.

Шаблон: русский — 2 занятия, профмат — 3 по 50 минут, физика — 4 по 45–50 минут, преподаватели — по одному занятию по профмату (60 минут) и физике (75 минут).

Через «⋯» меняются предмет, дата, плановое время и формат занятия; изменение даты переносит занятие на выбранный день. Темы вводить не нужно. «Сделано» влияет на процент, фактические минуты учитываются независимо от отметки. График занятий показывает фактические минуты по предметам за шесть недель до выбранной включительно. Баллы пробников вводятся по шкале 0–100.

Без Gist работает прежний локальный режим: данные привязаны к браузеру и адресу, удаляются при очистке данных сайта и не синхронизируются.
