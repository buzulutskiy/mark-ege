# Марк · Подготовка к ЕГЭ

Автономное приложение на русском языке, без регистрации, внешних библиотек и сетевых запросов. Весь исходный код находится в `dist`.

## Запуск

Надёжный способ: установите Node.js, откройте терминал в папке проекта и выполните:

```
npm start
```

Откройте http://127.0.0.1:4173 в браузере. Установка зависимостей не нужна.

Можно также открыть `dist/index.html` двойным щелчком. Сохранение при таком открытии зависит от браузера; рекомендуется запуск через `npm start`.

Для использования на телефоне разместите содержимое `dist` на любом статическом хостинге. Серверная база данных не требуется.

## Как пользоваться

- Для каждой впервые открытой недели создаётся шаблон из 11 занятий: русский — 2, профмат — 3 по 50 минут, физика — 4 по 45–50 минут, преподаватели — по одному занятию по профмату (60 минут) и физике (75 минут).
- Чекбокс «Сделано» влияет на процент выполнения недели. Фактическое время вводится отдельно и суммируется независимо от чекбокса.
- Кнопка «⋯» позволяет изменить занятие, дату, время и преподавателя, а также удалить его. Изменение даты переносит занятие, в том числе на другую неделю. На новой неделе сохраняется и базовый шаблон.
- Через «Добавить занятие» можно дополнить план.
- В блоке пробников добавляйте дату, предмет и итоговый балл 0–100 (не первичный балл). Цвета графика соответствуют цветам предметов. Через «⋯» можно исправить или удалить результат.
- История недель и пробников сохраняется автоматически в localStorage. Вкладки одного адреса синхронизируются.

## Хранение данных

Данные привязаны к браузеру и адресу приложения; между телефоном и компьютером они не синхронизируются. При очистке данных сайта история удаляется. В приватном режиме она может исчезнуть после закрытия окна. Всегда используйте один и тот же адрес для доступа к своей истории.

## Проверка

`npm run check` проверяет синтаксис JavaScript. Проект не требует сборки.
