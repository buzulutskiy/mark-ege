УЧИМСЯ РАДИ РЕЗУЛЬТАТА

Цели и контрольные точки

Баллы пока не назначены: сначала диагностика, затем цель с семьёй и преподавателями. Тематический прогресс строится по отметкам Марка. Проверочные работы и пробники дают независимую проверку; часы сами по себе не означают освоение.

Это наш рабочий план, не календарный норматив ФИПИ. Полные пробники заменяют часть обычных занятий. Проверки знаний — два новых небольших набора в разные дни (желательно через неделю), с оценкой преподавателя; процент первичных баллов не равен баллу ЕГЭ.
